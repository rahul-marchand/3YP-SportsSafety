DEPLOYMENT GUIDE - RUNNING ON YOUR PHONE

OPTION 1: NGROK (Recommended for testing)

1. Install ngrok:
   brew install ngrok
   
   Or download from: https://ngrok.com/download
   Sign up for free account if needed

2. Install backend dependencies:
   cd /Users/suleimanmahmood/Documents/3YP/src/eye_tracking/smooth_pursuit
   ./install.sh

3. Run backend with ngrok:
   ./run_with_ngrok.sh
   
   This will:
   - Start Python backend on localhost:8000
   - Start ngrok tunnel
   - Show you the public URL (e.g., https://abc123.ngrok-free.app)

4. Update mobile app:
   Edit: mobile_app/app_code/config.js
   Change BACKEND_URL to the ngrok URL shown

5. Run React Native app on your phone:
   Follow mobile_app/SETUP.txt to install and run the app

6. The app will connect to your backend through ngrok


OPTION 2: LOCAL NETWORK (Faster, no external dependencies)

1. Ensure phone and computer on same WiFi

2. Find your computer's IP:
   System Preferences > Network > WiFi > IP Address
   Or run: ifconfig | grep "inet "

3. Update mobile app config:
   Edit: mobile_app/app_code/config.js
   Change BACKEND_URL to: "http://YOUR_IP:8000"

4. Run backend:
   python3 backend.py

5. Run mobile app on phone


TROUBLESHOOTING:

- ngrok free tier has session limits (2 hours)
- ngrok URL changes each restart (paid tier gets static URLs)
- For WebSocket issues, ensure using ws:// or wss:// protocol
- Check ngrok dashboard: http://localhost:4040
